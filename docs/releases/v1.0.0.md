# g2rain-gateway-webmvc v1.0.0

## 首次 GHCR 镜像发布

`g2rain-gateway-webmvc` 是 G2rain（谷雨）开源智能体平台中的 Servlet/MVC.fn 统一入口网关实现。它负责动态路由、入口令牌/API Key/DPoP/签名与 API 权限策略、可信主体透传、响应适配、同步缓存和入口观测；不拥有身份、权限、路由、Token 或领域数据的主事实，也不单独交付平台的 SaaS、知识库、智能体或商业化能力。

该组件当前是中央 `gateway-service 1.0.0-draft` 的计划接入实现，不能据此宣称 Profile 已正式采用或已经完成环境集成验证。

## 构建与运行事实

- 项目版本：根 `pom.xml` 的 `revision` 为 `1.0.0`。
- 构建要求：JDK 25、Maven 3.9+；CI 使用 Temurin 25 并运行 `mvn -B -ntp clean verify`。
- 关键框架：Spring Boot 4.1.2、Spring Cloud 2025.1.4、Spring Cloud Alibaba 2025.1.0.0。
- 运行时：`com.g2rain.gateway.Application`，默认端口 `8083`，默认 profile 为 `dev`。
- 容器基础镜像：`eclipse-temurin:25.0.4.1_1-jre`；最终镜像含 `/app/app.jar`，入口为 `java -jar /app/app.jar`。

发布改动、工作流和本文件必须先进入 `main`；随后在该提交创建 `v1.0.0`。工作流会拒绝非 `vMAJOR.MINOR.PATCH` tag、非 `origin/main` 历史的提交、缺失/空发布说明或与 Maven 版本不一致的 tag。

## 安全与限制

镜像内的 Jar 打包了已跟踪的 `src/main/resources/application.yml`，该文件含 Nacos 开发默认用户名/密码。这些值会进入 `/app/app.jar`，不是 `.dockerignore` 可以治理的风险。生产 Token、DPoP 私钥、API Key、密码和 Nacos 凭据必须通过环境变量、Nacos 配置中心或密钥管理服务注入；不得写入仓库或镜像。

已知限制包括：当前 Maven Enforcer 发现 `g2rain-common:1.0.9` 与 SpringDoc 对 `swagger-annotations-jakarta` 的 2.2.46/2.2.55 上界冲突，历史记录另有 `g2rain-infra-api:1.0.0` 解析失败；安全过滤器的直接测试不足；请求/响应日志脱敏、开发默认凭据和请求体资源上限仍是已登记风险；Nacos、Basis、Infra、Redis 同步、IAM 契约与真实下游服务尚未完成端到端部署验证。
